# Retail Data Engineering Pipeline

## Project Overview
This project demonstrates an end-to-end retail data engineering pipeline using AWS, Snowflake, dbt, GitHub, and Jira.

## Technologies Used
- AWS S3 – Data storage
- Snowflake – Cloud data warehouse
- SQL – Data transformation
- dbt – Data modelling and testing
- Git & GitHub – Version control
- Jira – Project management

## Project Architecture

AWS S3 → Snowflake RAW → Snowflake STAGING → dbt Transformations → Snowflake MART

## Project Objectives
- Ingest retail data from AWS S3 into Snowflake.
- Build RAW, STAGING, and MART data layers.
- Transform data using SQL and dbt.
- Implement data quality checks.
- Automate data processing using Snowflake Streams and Tasks.
- Maintain project code using GitHub.
- Track project activities using Jira.
